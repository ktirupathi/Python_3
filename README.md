# 🐍 Python in 30 Days

### A Complete Python Learning Path — From Zero to Data Science & Deep Learning

> **Master Python end-to-end** in 30 days with hands-on examples, assignments, and capstone projects covering Data Analysis, Machine Learning, and Deep Learning.

---

## Who Is This For?

- **Complete beginners** who want to learn Python from scratch
- **Developers** from other languages looking to pick up Python quickly
- **Aspiring Data Scientists / ML Engineers** who need a structured learning path
- Anyone preparing for **Python technical interviews**

## Prerequisites

- A computer with Python 3.9+ installed ([Download Python](https://www.python.org/downloads/))
- A code editor (VS Code, PyCharm, or Jupyter Notebook)
- Basic math knowledge (algebra level)
- Curiosity and consistency!

---

## How to Use This Repository

### 1. Clone the repo

```bash
git clone https://github.com/ktirupathi/Python_3.git
cd Python_3
```

### 2. Set up a virtual environment

```bash
python -m venv venv
source venv/bin/activate        # macOS/Linux
venv\Scripts\activate           # Windows
pip install -r requirements.txt
```

### 3. Follow the weekly structure

Each week has its own folder with:

| Folder | Contents |
|--------|----------|
| `topics/` | Concept explanations with inline examples |
| `examples/` | Runnable Python scripts for each topic |
| `assignments/` | Practice problems — Basic, Intermediate, and Advanced |
| `solutions/` | Reference solutions (try on your own first!) |

### 4. Track your progress

- [ ] **Week 1** — Python Fundamentals & Core Concepts
- [ ] **Week 2** — Intermediate Python & File Handling
- [ ] **Week 3** — Data Analysis & Visualization
- [ ] **Week 4** — Machine Learning & Deep Learning
- [ ] **Capstone Projects** — End-to-End Real-World Projects

### 5. Work through assignments

Each topic has **3 difficulty levels**:
- **Basic** — Reinforce the concept
- **Intermediate** — Apply to real scenarios
- **Advanced** — Interview-level / production-level challenges

## 30-Day Roadmap Overview

### Week 1: Python Fundamentals (Days 1–7)

| Day | Topic |
|-----|-------|
| 1 | Python Setup, Syntax, Variables, Data Types |
| 2 | Operators, Type Casting, User Input |
| 3 | Strings — Slicing, Methods, Formatting |
| 4 | Lists & Tuples — CRUD, Slicing, Comprehensions |
| 5 | Dictionaries & Sets |
| 6 | Conditionals & Loops (for, while, nested) |
| 7 | Functions — Parameters, *args, **kwargs, Lambda |

### Week 2: Intermediate Python (Days 8–14)

| Day | Topic |
|-----|-------|
| 8 | List/Dict/Set Comprehensions, Generators, Iterators |
| 9 | File Handling — Read, Write, CSV, JSON |
| 10 | Error & Exception Handling, Custom Exceptions |
| 11 | Object-Oriented Programming — Classes, Objects, `self` |
| 12 | OOP — Inheritance, Polymorphism, Encapsulation, Abstraction |
| 13 | Modules, Packages, Virtual Environments, pip |
| 14 | Decorators, Context Managers, Regular Expressions |

### Week 3: Data Analysis & Visualization (Days 15–21)

| Day | Topic |
|-----|-------|
| 15 | NumPy — Arrays, Indexing, Broadcasting, Linear Algebra |
| 16 | Pandas — Series, DataFrames, Indexing, Selection |
| 17 | Pandas — Merging, Groupby, Pivot Tables, Time Series |
| 18 | Data Cleaning — Missing Values, Duplicates, Outliers |
| 19 | Matplotlib — Line, Bar, Scatter, Histogram, Subplots |
| 20 | Seaborn — Statistical Plots, Heatmaps, Pair Plots |
| 21 | Exploratory Data Analysis (EDA) — Full Walkthrough |

### Week 4: Machine Learning & Deep Learning (Days 22–30)

| Day | Topic |
|-----|-------|
| 22 | ML Fundamentals — Supervised vs Unsupervised, Scikit-learn Intro |
| 23 | Linear Regression & Polynomial Regression |
| 24 | Logistic Regression & Classification Metrics |
| 25 | Decision Trees, Random Forest, Ensemble Methods |
| 26 | K-Means Clustering, PCA, Unsupervised Learning |
| 27 | Model Selection — Cross Validation, Hyperparameter Tuning |
| 28 | Deep Learning — Neural Network Basics, TensorFlow/Keras Intro |
| 29 | CNNs for Image Classification |
| 30 | NLP Basics — Text Processing, Sentiment Analysis |

## Tips for Success

1. **Code daily** — Consistency beats intensity. Even 1 hour/day works.
2. **Type the code** — Don't copy-paste. Muscle memory matters.
3. **Break things** — Modify examples, see what breaks, understand why.
4. **Attempt assignments before viewing solutions** — Struggle is where learning happens.
5. **Build projects** — The capstones tie everything together; don't skip them.
